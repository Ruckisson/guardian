Why it matters
Telnet sends the login and the whole session in clear text.

Recommended change

ip domain name <DOMAIN>
crypto key generate rsa modulus 2048
ip ssh version 2
line vty 0 4

Skip the first two lines if an RSA key of 2048 bits or more already exists.

Before you apply

  • SSH already works: show ip ssh shows SSH enabled, version 2.0, and you can log in over SSH now.
  • An RSA key exists: show crypto key mypubkey rsa.
  • No tool still uses telnet (NMS, backup scripts, terminal servers): show users, show tcp brief.

2.HighHTTP server must be disabled, use HTTPS insteadIOS-MGMT-006

Area
Management access (MGMT)
Location
(global)
Config line
ip http server
Why it matters
The web interface over plain HTTP sends credentials in clear text. The IOS XE web UI was mass-exploited in 2023 (CVE-2023-20198).

Recommended change

no ip http server
no ip http secure-server

Turns off the web interface completely. Recommended when nothing uses it.

Before you apply

  • No feature in the config needs it: ip admission, parameter-map type webauth, redirect url, telephony-service.
  • Nothing connects to it: show ip http server history, show ip http server connection.

If the service is needed

If the web interface is needed, move it to HTTPS and restrict it:

ip http secure-server
ip http authentication local
ip http access-class ipv4 <MGMT_ACL>
no ip http server

Older IOS: ip http access-class <MGMT_ACL>. If web authentication (802.1X, guest portal) needs HTTP redirects, keep ip http server and add ip http active-session-modules none.

3.HighEnable password must not be used, use enable secretIOS-PASS-001

Area
Passwords (PASS)
Location
(global)
Config line
enable password <redacted>
Why it matters
The enable password is stored in clear text or with reversible type 7 encoding. Anyone who sees the config or a backup can read it.

Recommended change

enable algorithm-type scrypt secret <NEW_PASSWORD>
no enable password

Older IOS without scrypt: enable secret <NEW_PASSWORD>.

Before you apply

  • The IOS supports scrypt: enable algorithm-type ?.
  • Update the enable password in automation and NMS tools.
  • Set a new value. The old one was readable in the config, so treat it as leaked.

Why it matters
The account password is stored reversibly. A privilege 15 account exposed this way gives full control of the device.

Recommended change

no username admin
username admin privilege 15 algorithm-type scrypt secret <NEW_PASSWORD>

IOS won't add a secret to a user that has a password, so the account is removed and added again.

Before you apply

  • Re-add any other options from the original line (autocommand, view).

Why it matters
A read-write community lets anyone who knows it change the configuration or copy it off the device over SNMP.

7.MediumActive access ports must have port security or 802.1X/MABIOS-L2-001

Area
Layer 2 (L2)

Config line

Why it matters
Any device can be plugged into these ports, and the MAC address table can be flooded.

Recommended change

interface GigabitEthernet0/1
 switchport mode access
 switchport port-security maximum <MAX_MAC>
 switchport port-security violation restrict
 switchport port-security aging time 10
 switchport port-security aging type inactivity
 switchport port-security
interface GigabitEthernet0/2
 switchport mode access
 switchport port-security maximum <MAX_MAC>
 switchport port-security violation restrict
 switchport port-security aging time 10
 switchport port-security aging type inactivity
 switchport port-security

<MAX_MAC>: 1 for a single PC, 3 for an IP phone with a PC behind it, more for hypervisors.

Before you apply

  • Count the MAC addresses on each port: show mac address-table interface Gi0/1.
  • Check what is connected: show cdp neighbors Gi0/1 detail (phones, APs, small switches).

If the service is needed

If the network uses 802.1X or MAB, configure that instead. It needs a RADIUS server.

8.MediumTrunk native VLAN must not be VLAN 1IOS-L2-006⚠ Change both ends

Area
Layer 2 (L2)
Location
interface GigabitEthernet0/24
Config line
switchport mode trunk
Why it matters
Untagged traffic on the trunk lands in VLAN 1, which makes VLAN hopping with double-tagged frames possible.

Recommended change

vlan <NATIVE_VLAN>
 name NATIVE-UNUSED
interface GigabitEthernet0/24
 switchport trunk native vlan <NATIVE_VLAN>

Use one unused VLAN ID across the network, and put it on no access port.

Before you apply

  • Find the neighbour: show cdp neighbors Gi0/24 detail.
  • Nothing relies on untagged traffic on this trunk (APs, hypervisors, phones).

If the service is needed

If you can't change both ends now, vlan dot1q tag native tags the native VLAN too. The neighbour must support it and have it configured.

9.MediumVTY lines must restrict source addresses with an access-classIOS-MGMT-002⚠ May cut your access

Area
Management access (MGMT)
Location

Config line
no access-class under the line
Why it matters
Management logins are not limited by source address. Any host that can reach the switch can try to log in.

Recommended change

ip access-list standard <MGMT_ACL>
 permit <MGMT_NETWORK> <WILDCARD>
 deny any log
line vty 0 4
 access-class <MGMT_ACL> in vrf-also

Before you apply

  • Your own source IP is in the ACL: show users.
  • All management sources are in the ACL: jump hosts, NMS, backup and automation servers.
  • Check whether management uses a VRF: show vrf. If it does, keep vrf-also.
